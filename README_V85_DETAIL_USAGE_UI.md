# Coin Pattern Beta v85 — 상세분석 사용량 UI

v84의 상세분석 일일 사용량 정책과 서버 동작은 그대로 유지하고, 상세분석 화면의 사용량 표시 UI만 개선했습니다.

## 정책 유지
- 비회원: 하루 고유 코인 5개
- 무료 회원: 하루 고유 코인 20개
- PRO: 무제한
- 같은 코인을 다시 열어도 차감하지 않음

## UI 변경
- 상세분석 화면 상단에 `오늘 상세분석 X/Y개` 사용량 카드 표시
- 남은 개수와 사용률을 진행바로 표시
- 5/5 또는 20/20 사용 시 주황색 완료 상태로 표시
- PRO는 `💎 PRO · 무제한` 배지로 표시
- 모바일에서도 한 줄로 깨지지 않도록 반응형 처리
- 기존 상세분석 내용, 시작 방식, 데이터/서버 로직은 변경하지 않음
