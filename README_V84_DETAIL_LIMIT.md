# Coin Pattern Beta v84 — 상세분석 일일 사용량 제한

## 정책
- 비회원: 하루 고유 코인 5개
- 무료 회원: 하루 고유 코인 20개
- PRO: 무제한
- 같은 코인을 다시 열어도 차감하지 않음

## UX
6번째 비회원 상세분석부터 무료 회원가입/로그인을 안내합니다.
무료 회원이 21번째 고유 코인을 열려고 하면 PRO 안내를 보여줍니다.

## 서버
`server_auth_v38.py`에 `detail_usage` 테이블과 `/v1/detail-usage` 엔드포인트를 추가했습니다.
정식 운영에서는 익명 사용량을 device_id만으로 제한하지 말고 서버 쿠키/계정/부정사용 방지 정책을 함께 적용해야 합니다.
